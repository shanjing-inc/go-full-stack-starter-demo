# TDesign 样式扩展与改动审查

日期：2026-10-19。范围：相对 `1940fdf` 的全部 TDesign 接入改动，包括既有暂存内容及本轮未暂存的样式扩展。没有创建任务、改动暂存区或提交。

## 审查结果与修复

| 问题                                                             | 处理结果                                                                                                                         |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Tabs 只展示默认一种样式，容易误认为只能使用这一种                | 保持官方属性接口，分别展示 line、tag；两组状态独立。card、指示线、均分、滑动及吸顶配置继续可用                                   |
| Button 的项目语义映射限制了官方外观，size 也只接收项目别名       | 保留 variant，新增 appearance 覆盖原生 variant；theme、shape、icon、ghost 等可直接配置，保留所有官方尺寸与原别名、禁用及加载保护 |
| Tag 固定 light 外观，缺少形状等属性及关闭入口                    | 新增 appearance 和官方属性类型；关闭事件归一为项目触摸事件，并显式登记真实模板绑定                                               |
| Input 类型缺少官方布局、图标等配置，显式 status 被固定值覆盖     | 从现有平台接口及官方属性组合派生，显式状态有效，invalid=true 仍优先；新增 clear 模板绑定和受控回填示例                           |
| EmptyState 固定 inbox，不能替换图像                              | 开放 icon/image 和样式属性，保持 title/description/action 组合与原默认图标                                                       |
| Tabs stickyProps、Button loadingProps 暴露微信 property 描述类型 | 仅对已确认的嵌套字段解包，接受普通 offsetTop/zIndex、theme 等属性；正反类型契约覆盖                                              |
| 页面请求测试固定等 80ms，在并行构建时过早断言                    | 首轮全量测试复现一次，改为等待请求按钮结束加载，5 秒超时。卸载测试保留独立观察期                                                 |

审查同时核对了依赖及两份锁文件、生成资源忽略、构建插件的动态图片/样式/默认值/事件/watch 保留、系统主题与官方变量、所有组件包装、九个页面及业务回归和文档。其他以官方属性派生的组件已保留外观配置，未增加变体注册表或复制实现。未发现需要阻止此次扩展的其他确定代码缺陷。

## 行为约定

- 项目语义与官方外观分开配置，Button/Tag 的 theme、appearance 优先于语义 variant 的默认映射；已有调用的默认输出保持原样。
- Button 的 fullWidth 优先于 block；sm/default/lg 别名保持，同时接收官方尺寸。平台回调和禁用/加载保护继续由原包装管理。
- Input 清除由官方 clear 事件触发，不自动发 change；受控页面在 onClear 中回填空字符串。
- Tabs 两种示例继续使用 Card 分组，保持原生父子节点；不修改全站布局或真实底栏。
- 新增样式优先使用现有官方属性及公开主题变量；类型、包装、模板与设备实际消费分别验收，不宣称所有官方能力均已支持。
